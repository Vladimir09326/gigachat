# gigachat
1. Растровый файл (PNG) хранит картинку как сетку пикселей и лучше подходит для сложных иллюстраций с тенями и переходами цветов, а векторный SVG описывает фигуры формулами — он мало весит и остаётся чётким при любом увеличении.
2. Выбрана пара фиолетовый и жёлтый. На цветовом круге они расположены напротив друг друга и называются дополнительными (фиолетовый — основной, жёлтый — акцентный).
3. Цвет кнопки: #EAB308 в HEX и rgb(234, 179, 8) в RGB. Для полноцветной печати используется модель CMYK.
